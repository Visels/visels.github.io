# Elvis Kipchumba - Portfolio

A modern, responsive portfolio website showcasing my skills, experience, and projects as a Software Engineer.

## 🚀 Features

- **Modern Design**: Clean, professional design with smooth animations
- **Responsive Layout**: Optimized for all device sizes
- **Interactive Elements**: Smooth scrolling, hover effects, and animations
- **Professional Sections**: About, Experience, Projects, Education, Resume, and Contact
- **GitHub Integration**: Live GitHub contribution calendar
- **3D Elements**: Interactive 3D components using Three.js

## 🛠️ Tech Stack

- **Frontend**: React 19, Vite
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion, GSAP
- **3D Graphics**: Three.js, React Three Fiber
- **Icons**: React Icons
- **Typewriter Effect**: Typewriter-effect

## 📋 Sections

1. **Home**: Landing page with introduction

## 🚀 Getting Started

### Prerequisites

- Node.js 18.0.0 or higher
- npm or yarn package manager

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd Portofolio-Rasyid
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:5173`

### Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build
- `npm run lint` - Run ESLint

## 🎨 Customization

### Personal Information
Update the following files to customize for your portfolio:
- `src/components/About.jsx` - Personal description
- `src/components/Experience.jsx` - Work experience
- `src/components/Projects.jsx` - Project details
- `src/components/Education.jsx` - Educational background
- `src/components/LandingPage.jsx` - Hero section content

### Styling
The project uses Tailwind CSS for styling. Modify the classes in component files to change colors, spacing, and layout.

### Images
Replace images in the `src/assets/` folder with your own photos and project screenshots.
